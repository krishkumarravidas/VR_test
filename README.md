# VR Test Build

This repository contains the installation scripts for the VR project. 

## 📦 Download the Game Binaries
Because the build files are too large for GitHub, download the `.apk` and `.obb` files from the link below:
👉 **[CLICK HERE TO DOWNLOAD THE BUILD FILES]([https://drive.google.com/drive/folders/1UMbb0rMfRB9jRgP63Zymv1ihwk0J8v59?usp=sharing](https://drive.google.com/drive/folders/1UMbb0rMfRB9jRgP63Zymv1ihwk0J8v59?usp=sharing))**

## 🚀 How to Install on Your Android/Quest Device
1. Download the files from the link above.
2. Place the `.apk` and `.obb` files into the same local folder on your computer where you downloaded this repository.
3. Connect your Android or Meta Quest device via USB (make sure Developer Mode is enabled).
4. Double-click `Install_VR_TEST-arm64.bat` to automatically install the game onto your device!
